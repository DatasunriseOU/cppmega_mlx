Parquet fixtures

16 dirty fixtures декодированы PyArrow и сравнены с HEAD. Rows, columns, Arrow schema и decoded values совпадают. Отличаются writer metadata (parquet-cpp-arrow version 21.0.0 → 24.0.0) и физические compressed/uncompressed sizes column chunks; это file-representation churn, не изменение данных/schema. Binary fixture churn не включается в production commit.

Test harness

Полный suite запускается с PYTHONSAFEPATH=1. Test fixture удаляет foreign PYTHONPATH и возвращает только текущий checkout для дочерних python -m scripts.... Parser/converter fixtures явно отключают admission threshold, потому что проверяют schema/provenance; production memory guard остаётся с default 10 GiB и fail-closed.
