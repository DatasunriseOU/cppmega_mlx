Path C Fusion IR Audit

Date: 2026-05-19

Scope: current high-level Path C fusion infrastructure for model-route brick chains such as mamba3_scan + residual/RMSNorm + m2rnn_packed_post + residual/RMSNorm + attention_qkv_projection + sparse_mla_fp8_apply.

Bottom line: the IR-level graph, descriptor-driven single-entry schedule generator, explicit production schedule contract, semantic fail-closed gate, cache/audit gates, Z3 pass attachment, and TileLang lowerer path are in place. The named Mamba3 schedule is now a tagged acceptance preset over reusable brick descriptors, while generic model-route chains derive their loop extent and external ABI shapes from the concrete model config carried in PathCModelShapeEnv. The selected local_gb10_quarter model-route path currently resolves to buffer_extent=4096 and row-local hidden storage for internal edge buffers (schedule_generator_status=loop_per_brick_descriptor_fragments), but it is still untrusted and Path C fusion must not be defaulted. The schedule contract and compile cache key now include a shape_env_key, so two models with the same brick chain but different sequence/model dimensions cannot silently reuse the same fused schedule contract.

Current Blockers

Edge Observed Raw ABI Why It Blocks Auto Fusion
mamba3_scan -> m2rnn_packed_post : scan_y Mamba3 raw candidate y:1x2x2x4:float32; M2RNN raw candidate conv_input:1x2x12:float32. The logical scan_y edge is not exposed by both raw PrimFunc ABIs and the candidate shapes do not match.
m2rnn_packed_post -> fp8_prepare : post_y M2RNN raw candidate post:1x2x4:float32; FP8 prepare input post_y:96:float32. This is not the real model edge. The production FP8 producer consumes the attention-normalized hidden state after residual add and RMSNorm, then runs attention Q/KV projection before quantization.
mamba3_scan -> m2rnn_packed_post HybridTinyBlock uses pre-norm residual blocks: each route sees RMSNorm(hidden), and each output is added back to the residual stream. The fused schedule must include a mamba3_residual_to_m2rnn_norm style bridge. Raw mamba3 output cannot be treated as direct m2rnn input.
m2rnn_packed_post -> fp8_prepare CausalSelfAttention.prepare_sparse_mla_fp8 owns attention_qkv_projection: Q projection, sparse KV projection, optional RoPE, per-token FP8 quant, and sparse indices. The fused graph needs an explicit attention_qkv_projection producer node. A generic post_y prepare node is only a shape-specialized helper, not the production edge.
fp8_prepare -> sparse_mla_fp8_apply : q_fp8/q_scale/kv_fp8/kv_scale Resolved for the fused prepare producer: q_fp8 and kv_fp8 now expose uint8 e4m3fn storage, matching the prepared apply ABI. This edge no longer blocks on raw dtype. The production schedule still must keep these prepared buffers internal and keep indices as an external input or add a real indices producer.
